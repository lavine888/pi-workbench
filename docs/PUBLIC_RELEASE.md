- 枚举全部原有目录、隐藏文件、脚本、源码、配置与文档，读取可读文本；ZIP 内 36 个文件也检查内容。4 个 EXE 只检查元数据与 SHA-256，未分析内部载荷或运行，全部排除公开。

- 上游 v0.84.1 的文件通过下载与实际差异比对确认；许可证原文保留，未知内容逐文件记录。
- 5 个公开 TypeScript 模块通过 Node 的类型剥离与 `node --check`。这是语法验证，不能代替 TypeScript 类型检查。
- 本机 Pi 0.84.2 的真实扩展加载器成功加载两个公开入口：harness 注册 5 个事件，子代理注册 `subagent` 工具，无加载错误。没有执行工具、模型任务、并发、超时或取消路径。
- 原有 `demo-project/src/test.js` 实际输出 **1 项通过、4 项失败，退出码仍为 0**；输出含密码字段。本次仅保留过滤后的统计，不把这个测试计为通过，也不改变原练习。
- 使用已安装 `ignore` 库核对 `.gitignore`：30 个候选文件没有被屏蔽，101 个原有文件均被忽略；额外 14 个私有路径探针均被忽略。
- 安装复制步骤在独立测试目录执行；空配置经真实 SettingsManager 读取无错误，两个扩展被自动发现并加载。CLI `--help` 使用隔离的 agent 目录成功运行；未修改原全局状态。
- 四个公开角色经 Pi frontmatter 解析有效且没有模型覆盖；七个提示经 Pi 真实模板加载与参数展开验证，合成参数被替换且包含显式 project 作用域指令。

## 数据与风险处理

原始遥测、记忆、临时状态、个人运维资料、安装包和归档均保留原位并排除公开。没有删除敏感原文件，也没有把个人路径搬入公开配置。源码副本没有发现需要替换的本机绝对路径；四个角色副本去除了本机模型选项，七个提示副本明确项目角色作用域，专用 DeepSeek 提示没有纳入候选。配置示例为空、记忆示例为新建合成结构。

认证相关命中不自动认定为有效凭据：运维脚本涉及读取本地认证及请求头，演示代码含密码样例，均排除公开。详细位置、行号、类别与建议保存在 `.local-audit/findings.json`；该目录被显式忽略，公开文档不包含敏感值、整行证据或个人标识。

文本模式扫描不能证明不存在所有秘密。二进制内部、来源权限、其他仓库历史、运行时生成内容和外部部署都没有得到安全保证；本次不称“已可安全公开”。

5. 对最终候选再执行 `python scripts/prepare-public-release.py --check`；如果增加文件，同步清单、来源、忽略规则和检查。
6. 只从新建候选目录准备将来仓库。若以后引入 Git 或历史，重新检查追踪状态与全部历史，必要时取消追踪、轮换凭据；未经授权不自动改写历史。

生成本地候选：

```console
python scripts/prepare-public-release.py --output .local-audit/release-candidate
```

已存在的候选目录会拒绝覆盖；重新生成时指定一个新的 `.local-audit/` 子目录。导出不执行任何 Git、npm 发布或联网操作。
