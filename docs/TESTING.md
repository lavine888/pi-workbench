## 不调用模型的可复现测试

已测试环境：Windows、Node.js 24.15.0。使用 Node 原生 TypeScript 加载与标准库测试运行器，无需根 package、npm 安装、tsx、模型配置或联网。在仓库根目录运行：

```console
node --test tests/subagent.test.mjs
```

**实际结果：19 项通过，0 项失败，0 项跳过；模型调用数为 0。** 测试运行真实的子代理服务，任务进程替换为明确标注的[合成 CLI](../tests/fixtures/child-cli.mjs)。它不是 Pi 或模型服务，只提供可控的输出、错误和挂起行为。不得把测试结果描述为模型工作流成功率。

| 检查 | 验证的行为 |
| --- | --- |
| 服务启动和未使用时关闭 | 不调用 `npx`；关闭未启动的管理器不会创建服务 |
| 配置与文本输出 | 传递模型、工具、工作目录、角色提示；正确拼接被分块的 UTF-8 文本 |
| 请求和通知路由 | 数字／字符串 ID 保持类型；同角色并发任务各自收到进度 |
| 调度 | 超过槽位数的请求完成后，空闲槽位可复用，队列清空 |
| 取消 | 已运行任务终止；排队任务取消后不启动；预先取消的任务不启动服务 |
| 超时 | 任务、服务启动和请求超时均返回失败并停止相应进程 |
| 错误 | 子进程非零退出和启动失败均报告失败，后续请求仍可执行 |
| 清理 | 正常完成、取消和关闭清理本次临时提示；关闭服务终止合成后代进程；stdin 断开后服务退出 |
| 回退 | 直接启动使用相同的进程处理与参数；取消或空输出不触发第二次启动，空输出报告失败 |
| 工具限制 | 显式空工具列表通过 `--no-tools` 传递 |

测试运行器会在系统临时目录创建合成工作目录，清理前核对其解析后的父目录和专用名称前缀。生产代码仅清理自己创建的提示文件及其空目录，不递归删除未知内容。

## 失败复现与修复边界

修复前，Windows 实际启动复现返回 `spawn npx ENOENT`；原客户端在原生 ESM 加载下使用未定义的 `__dirname`。首轮新增检查也捕获了 Windows 启动失败的负退出码处理问题，之后修正为明确的失败结果。

现在服务使用当前 Node 启动可擦除类型的 TypeScript，独立服务只依赖内置模块。CLI 定位核对包元数据，不把测试入口、服务脚本或命令包装器当作 Pi CLI。仅服务启动失败允许回退；提交任务后，协议断开、超时或空结果均不会自动重放可能已经修改文件的任务。

两条执行路径共享五分钟任务超时。正常关闭通过请求或 stdin EOF 取消工作并等待清理；协议失效时紧急终止已拥有的进程。强行终止操作系统或服务进程可能留下临时提示，不能宣称所有异常情况下都保证清理。
